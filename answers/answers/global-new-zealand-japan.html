GTA VI / Cross-region buying questions

Global, New Zealand or Japan: what do those labels prove?

2026-11-19 02:56 JST · Listing evidence, not a purchased-copy test.

They are not a substitute for the exact platform, regional listing and product code.

Game*Spark reports three PS5 versions described as global, New Zealand and Japan. That is secondary reporting, not a complete SKU inventory verified by this guide. We have not independently mapped every retailer SKU or PlayStation product ID to those labels.

What the checker actually covers

PS5 results cover the Japan and US official support tables, not a universal global-version entitlement. New Zealand is not encoded as a verified PS5 language result. Do not choose US and assume it verifies a New Zealand product.

Code region and game language are different checks

Sony's GTA VI code compatibility guide says a Japan code is for Japan accounts; a US/Canada code is for US or Canada accounts; an Australia/New Zealand code is for accounts registered in either Australia or New Zealand. Check the supported group on the box. This does not independently establish the languages included in that download.
